Server address
{{ adms_host }}

Enter the address without https:// and without a trailing slash. Leave the communication key as the default (0) only if you have not set one.

Check reachability first

Open this in a browser on the same network as the device. It should say OK:

{{ adms_probe_url }}
If it does not connect
  • The device needs internet access — check its network cable and DHCP.
  • Firmware must support ADMS. Check Menu → Info for a firmware version and an ADMS or Cloud Server option.
  • Very old firmware only supports HTTP on port 80. If the device rejects port 443, it needs a firmware update to push over HTTPS.
  • Confirm the serial number registered here matches the one in Menu → Info → Device Serial Number exactly.
