{# Double-submit the CSRF token on every form. Flask-JWT-Extended pairs the access cookie with a CSRF value and rejects any cookie-authenticated write that does not present both. HTMX requests carry it in the `X-CSRF-TOKEN` header (set on via hx-headers), but a plain `method="post"` form sends nothing, so the check fails and the user is bounced to the sign-in page — which looks like being logged out at random. Rather than hand-editing dozens of forms, inject a hidden field into every POST form. This runs on DOMContentLoaded and again after any HTMX swap, so forms that arrive by HTMX are covered too. HTML provides no "form submitted" event to cancel a native submission, so the reliable approach is to refresh the field on every DOM change. That keeps the value current across page loads with no stale-token failures. NOTE: this block must NOT be wrapped in {% raw %}. The token below has to be interpolated at render time; a raw block would emit the Jinja expression verbatim and produce a JavaScript syntax error, silently breaking every form. #}
