Authentication

  1. POST /api/v1/auth/login with {"email": "...", "password": "..."}.
  2. Read data.tokens.access_token from the response.
  3. Send it as Authorization: Bearer <token>.
  4. Rotate with POST /api/v1/auth/refresh; the previous refresh token is revoked server-side on every rotation.

Device webhook

Devices post to POST /hooks/biometrics/punch with X-Device-SN and X-Device-Secret headers. Retries are safe: an identical punch is detected by its idempotency hash and answered with duplicate: true.
